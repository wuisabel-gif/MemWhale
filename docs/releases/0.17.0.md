# MemoryWhale 0.17.0 — Recall in Cursor

**Release date: October 3, 2026**

**Product: 0.17.0 · Rust core: 0.8.1 · SQLite schema: 13**

0.16 gave Claude Code proactive recall: when an error comes back, the agent is
told what fixed it last time, and when a fix works it is asked to save the
lesson. 0.17 brings the same notes to Cursor, and pairs with Delphin 0.5, where
one command sends that fix to the agent.

The CLI, web UI, and desktop app use product version **0.17.0**.
`memorywhale-core` is **0.8.1**: its only change is the `dirs` 7 update.
Existing databases stay on schema **13**.

## Install or upgrade

Prebuilt binaries cover Linux x86_64/aarch64 and macOS. The installer resolves
the current published release and verifies its published checksum:

```bash
(
  set -eu
  installer="$(mktemp)"
  trap 'rm -f "$installer"' EXIT
  curl -fsSL https://raw.githubusercontent.com/wuisabel-gif/MemWhale/7c3864c743cec9a8fa813dcc0b2459cc2859c849/install.sh -o "$installer"
  printf '%s  %s\n' '3e0cad72b29c1894d5ff5f7c30b099537f96501801c14b6320c12e169a3ac8d6' "$installer" | shasum -a 256 -c -
  sh "$installer"
)
```

To request this exact CLI release from crates.io after it is published:

```bash
cargo install memorywhale-cli --version 0.17.0 --locked
```

Or use Homebrew:

```bash
brew tap wuisabel-gif/memorywhale https://github.com/wuisabel-gif/MemWhale
brew install memorywhale
# If already installed:
brew update
brew upgrade memorywhale
```

The installer and Homebrew track their published release metadata rather than
pinning this document's version; check what was installed. Make sure the chosen
binary directory is on `PATH` (`~/.local/bin` for the installer or
`~/.cargo/bin` for Cargo):

```bash
mw --version
mw doctor
```

From a source checkout, build all helpers from the repository root:

```bash
cargo build --release -p memorywhale-cli --bins
```

The CLI does not require the desktop shell's GTK/WebKit libraries. Windows
users can use WSL. See [Getting started](../guides/getting-started.md) and the
[Linux guide](../../linux/README.md) for platform setup and Debian packaging.

## What changed

### Proactive recall for Cursor (#388)

The Shell capture hook that `mw integrate cursor --capture` installs now returns
the same one-line note as the Claude Code hook, through Cursor's documented
`additional_context` hook output:

- a failure whose error a later, different command fixed before gets that fix;
- a command that passes right after the same command failed, with no note saved
  since, gets a request to save the cause and the fix with `remember`.

Hooks already installed pick this up when the binaries are upgraded.
`MEMORYWHALE_HOOK_FEEDBACK=0` turns the notes off for Cursor and Claude Code.
Cursor reports some failures (timeouts, denied permissions, cancellations)
without an exit code; those are recorded but get no note.

### With Delphin 0.5

[Delphin](https://github.com/wuisabel-gif/Delphin) 0.5 adds `:fix`: when its
live MemoryWhale hint names a past fix, typing `:fix` sends the agent a prompt
to check whether that fix applies. The fix is only quoted, never run.

### Dependencies and tooling

- Tauri 2.12 on both the Rust and JavaScript sides (#368, #373), vite 8.3.1,
  lucide 1.48, vitest 5 (#374), thiserror 2 (#369), dirs 7 (#370),
  ratatui 0.30 (#372), and getrandom 0.4 (#387, which also renames the call to
  `getrandom::fill`).
- `dirs` 7 only changes a Windows folder MemoryWhale does not use; the database
  location is unchanged on every platform.
- CI runs on Node 22, since Node 20 reached end of life and vitest 5 needs
  22.12 or newer (#386).

### Docs

- A demo GIF of proactive recall in the README (#389).
- Project docs (constitution, philosophy, vision, SOP, handoff, Jetson testing,
  troubleshooting) moved to `docs/project/`, and the ecosystem page to
  `docs/ECOSYSTEM.md` (#391).
- Refreshed launch drafts (#390).

## Upgrade and compatibility

- Cursor users with `mw integrate cursor --capture` see the notes after
  upgrading; there is nothing to re-run. Behavior for other agents is unchanged.
- Building the frontend from source needs Node 22.12 or newer.
- Links to the moved docs at the repository root now live under `docs/project/`
  and `docs/ECOSYSTEM.md`.
- No schema change: schema 13 databases open as schema 13.

## What this release does not promise

- The Cursor notes are tested with hook payloads built from Cursor's
  documentation, not yet in a live Cursor session (#392).
- Past fixes are matched on error text, and the suggested fix is the next
  successful different command, which is usually but not always the fix.
- Codex does not get notes yet; MemoryWhale does not capture Codex commands
  (#393).
