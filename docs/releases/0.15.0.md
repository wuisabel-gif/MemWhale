# MemoryWhale 0.15.0 — Delphin Bridge

**Release date: September 30, 2026**

**Product: 0.15.0 · Rust core: 0.8.0 · SQLite schema: 13**

0.15 connects MemoryWhale to [Delphin](https://github.com/wuisabel-gif/Delphin),
the duplex wrapper that lets you keep talking to an agent while it works. When
an error scrolls past in the agent's output, Delphin now asks MemoryWhale
whether it has seen it and shows the answer while the agent is still going:

```text
🐬 MemoryWhale: seen 2 times, the fix was: xcode-select --install
```

The CLI, web UI, and desktop app use product version **0.15.0**.
`memorywhale-core` stays at **0.8.0**; nothing in it changed. Existing
databases stay on schema **13**.

## Install or upgrade

Prebuilt binaries cover Linux x86_64/aarch64 and macOS. The installer resolves
the current published release and verifies its published checksum:

```bash
(
  set -eu
  installer="$(mktemp)"
  trap 'rm -f "$installer"' EXIT
  curl -fsSL https://raw.githubusercontent.com/wuisabel-gif/MemWhale/7c3864c743cec9a8fa813dcc0b2459cc2859c849/install.sh -o "$installer"
  printf '%s  %s\n' '3e0cad72b29c1894d5ff5f7c30b099537f96501801c14b6320c12e169a3ac8d6' "$installer" | shasum -a 256 -c -
  sh "$installer"
)
```

To request this exact CLI release from crates.io after it is published:

```bash
cargo install memorywhale-cli --version 0.15.0 --locked
```

Or use Homebrew:

```bash
brew tap wuisabel-gif/memorywhale https://github.com/wuisabel-gif/MemWhale
brew install memorywhale
# If already installed:
brew update
brew upgrade memorywhale
```

The installer and Homebrew track their published release metadata rather than
pinning this document's version; check what was installed. Make sure the chosen
binary directory is on `PATH` (`~/.local/bin` for the installer or
`~/.cargo/bin` for Cargo):

```bash
mw --version
mw doctor
```

From a source checkout, build all helpers from the repository root:

```bash
cargo build --release -p memorywhale-cli --bins
```

The CLI does not require the desktop shell's GTK/WebKit libraries. Windows
users can use WSL. See [Getting started](../guides/getting-started.md) and the
[Linux guide](../../linux/README.md) for platform setup and Debian packaging.

## What changed

### Delphin bridge (#362)

- **`mw integrate delphin`** checks that Delphin 0.4.0 or newer is installed and
  prints the command to run: `delphin --memorywhale -- claude`. No database
  path to type.
- **`mw turns`** records conversation turns that Delphin streams to it as JSON
  lines. Turns go through the same redaction, size cap, and capture rules as
  every other capture, so Delphin no longer writes MemoryWhale's database
  directly and a secret printed by the agent is stored as `[REDACTED]`.
- **`mw hint <error line>`** answers "have we seen this?" in one line. It matches
  the error text against recorded failures, ignoring a UI prefix such as
  `⎿ Error:`, and names the first later successful, different command in the
  same directory. It prints nothing for an unseen error.
- The CLI now creates the `agent_turns` table itself, with Delphin's optional
  `turn_group_id` column. Databases created by the desktop app gain the column
  when the CLI opens them.

### Website

- A dolphin swims in the hero ocean next to the whale; clicking it opens
  Delphin (#363).

## Try it

```bash
brew install wuisabel-gif/delphin/delphin   # or: cargo install delphin
mw integrate delphin
delphin --memorywhale -- claude
```

## Upgrade and compatibility

- New commands only; existing commands behave as in 0.14.
- The older route, `delphin --db <MemoryWhale database>`, still works, but it
  skips redaction. Prefer `--memorywhale`.
- Delphin 0.4.0 is needed for `--memorywhale`. With an older `mw`, Delphin
  reports once that recording is off for the session and keeps running.
- No schema version change: schema 13 databases open as schema 13.

## What this release does not promise

- Hints match error text, not meaning. A reworded error is a new error, and the
  suggested fix is the next successful different command, which is usually but
  not always the fix.
- Redaction catches common secret shapes. It is best effort, not a guarantee.
