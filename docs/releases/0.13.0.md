# MemoryWhale 0.13.0 — Feedback-Aware, Portable Memory

0.13 makes retrieval feedback do something and makes memory move between
machines. Feedback recorded in 0.12 was display-only; now it can shape ranking,
and it travels with `import`/`push`/`pull` instead of being left behind.
Capture still writes the store; retrieval still reads it; core stays generic.

The CLI, web UI, and desktop app use product version **0.13.0**.
`memorywhale-core` is **0.7.0** (adds `encode_id`, the inverse of `decode_id`).
Existing databases stay on schema **13**; there is no migration.

## What changed

### Retrieval: feedback can shape ranking (opt-in)

- **Feedback-adjusted ranking** (#349): `mw search --use-feedback` (and MCP
  `search_memory` `use_feedback: true`) reorders results by your recorded
  feedback. Active `helpful` marks lift a memory; `irrelevant`/`outdated`/
  `contradicted` lower it, by a bounded amount that breaks near-ties without
  overriding a real relevance gap. It never rewrites the relevance score or
  filters results, and `--explain` shows the adjustment. Default ranking and
  output are unchanged unless you pass the flag.

### Memory: feedback and links travel between machines

- **Portable feedback and links** (#348): `mw import` / `mw pull` / `mw push`
  now carry `retrieval_feedback` and typed `memory_links`, remapping each
  memory's row id to its id on the destination. Rows whose target memory did
  not import are skipped and counted; re-import is idempotent. Feedback is no
  longer machine-local.

## Upgrade and compatibility

- `memorywhale-core` 0.7.0 adds `encode_id`; existing public items are
  unchanged. The CLI depends on this version, so core is republished for
  crates.io.
- No schema migration: schema 13 databases open as schema 13.
- Default search output and ranking are unchanged unless you pass
  `--use-feedback` (or `--mode` / `--ranking`).

## What this release does not promise

- Feedback ranking is a bounded, opt-in reorder, not a learned model.
- Transfer remaps row ids on import; it does not change the primary-key
  scheme. Cross-machine identity beyond import remains an RFC topic.
