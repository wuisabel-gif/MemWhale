# MemoryWhale 0.11.1 — Publish core provenance

**Release date: September 20, 2026**

**Product: 0.11.1 · Rust core: 0.5.1 · SQLite schema: 10**

This patch exists so `cargo install memorywhale-cli --version 0.11.1 --locked`
can compile against crates.io. `memorywhale-cli` 0.11.0 used
`memorywhale_core::provenance::AGENT_CURSOR` and `AGENT_CODEWHALE`, but
published `memorywhale-core` 0.5.0 only exported Claude and Rho. Core **0.5.1**
adds those constants and a five-entry `SUPPORTED_AGENTS` list.

There is no schema migration and no intentional CLI behavior change beyond
publishability. Prefer 0.11.1 for crates.io and Homebrew-from-source. GitHub
tarballs for 0.11.0 were built from the workspace path dependency and already
include Cursor and Codewhale capture.

```bash
cargo install memorywhale-cli --version 0.11.1 --locked
```
