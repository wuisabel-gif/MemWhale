# MemoryWhale 0.16.0 — Proactive Recall

**Release date: October 2, 2026**

**Product: 0.16.0 · Rust core: 0.8.0 · SQLite schema: 13**

Until now, MemoryWhale waited to be asked. A small Terminal-Bench pilot showed
what that costs: an agent ran 91 commands, MemoryWhale recorded every one, and
the agent never searched its memory or saved a lesson. In 0.16, memory speaks
first at the two moments where it matters, and stays quiet the rest of the
time:

```text
MemoryWhale: this error was seen once, the fix was: xcode-select --install. Check whether it applies here.
```

The CLI, web UI, and desktop app use product version **0.16.0**.
`memorywhale-core` stays at **0.8.0**; nothing in it changed. Existing
databases stay on schema **13**.

## Install or upgrade

Prebuilt binaries cover Linux x86_64/aarch64 and macOS. The installer resolves
the current published release and verifies its published checksum:

```bash
(
  set -eu
  installer="$(mktemp)"
  trap 'rm -f "$installer"' EXIT
  curl -fsSL https://raw.githubusercontent.com/wuisabel-gif/MemWhale/7c3864c743cec9a8fa813dcc0b2459cc2859c849/install.sh -o "$installer"
  printf '%s  %s\n' '3e0cad72b29c1894d5ff5f7c30b099537f96501801c14b6320c12e169a3ac8d6' "$installer" | shasum -a 256 -c -
  sh "$installer"
)
```

To request this exact CLI release from crates.io after it is published:

```bash
cargo install memorywhale-cli --version 0.16.0 --locked
```

Or use Homebrew:

```bash
brew tap wuisabel-gif/memorywhale https://github.com/wuisabel-gif/MemWhale
brew install memorywhale
# If already installed:
brew update
brew upgrade memorywhale
```

The installer and Homebrew track their published release metadata rather than
pinning this document's version; check what was installed. Make sure the chosen
binary directory is on `PATH` (`~/.local/bin` for the installer or
`~/.cargo/bin` for Cargo):

```bash
mw --version
mw doctor
```

From a source checkout, build all helpers from the repository root:

```bash
cargo build --release -p memorywhale-cli --bins
```

The CLI does not require the desktop shell's GTK/WebKit libraries. Windows
users can use WSL. See [Getting started](../guides/getting-started.md) and the
[Linux guide](../../linux/README.md) for platform setup and Debian packaging.

## What changed

### Proactive recall for Claude Code (#376)

The capture hook that `mw integrate claude` installs already records every Bash
command. It now also adds one line to what the agent sees next, at two moments:

- **A failure MemoryWhale has seen fixed before.** When a command fails with an
  error that a later, different command fixed in the past (same directory), the
  agent is told that fix. It uses the same matcher as `mw hint`, and says
  nothing when no fix is known.
- **A pass right after a failure.** When a command succeeds right after the
  same command failed in the same directory, and no note was saved in between,
  the agent is asked to save the cause and the fix in one sentence with
  `remember`. That conclusion is what a raw command log does not capture.

Existing installs pick this up when the binaries are upgraded; there is nothing
to re-run. Set `MEMORYWHALE_HOOK_FEEDBACK=0` to record silently.

### Ten languages (#379, #381)

- The README and the website now come in **Spanish** and **Brazilian
  Portuguese**, alongside English, Arabic, German, French, Simplified and
  Traditional Chinese, Korean, and Japanese.
- Translated READMEs moved from the repository root to `docs/i18n/`. The
  translation checker now also fails a translation whose relative links were
  not rewritten for that folder.

### Benchmarks and docs

- **Terminal-Bench pilot report** (#375): small pilots verified that the
  MemoryWhale run is wired correctly (MCP connected, every command recorded,
  memory carried between tasks) and measured per-task cost. No score is claimed
  yet. The guide now documents subscription auth and a longer setup timeout.
- **Ecosystem** (#366): Joule joins Delphin and ContextGC, and the Delphin setup
  shows `delphin --memorywhale`.

### Fixed

- Builds cleanly on the newest stable Rust, which deprecates
  `AtomicUsize::fetch_update` (#380).
- A `mw-serve` test no longer fails intermittently on busy CI machines (#383).

## Upgrade and compatibility

- Claude Code users see the new one-line notes after upgrading. Other agents
  and plain `mw` capture behave as in 0.15.
- No schema change: schema 13 databases open as schema 13.
- Links to translated READMEs at the repository root (`README.de.md` and so on)
  now live under `docs/i18n/`.

## What this release does not promise

- Past fixes are matched on error text, not meaning, and the suggested fix is
  the next successful different command, which is usually but not always the
  fix. The note says to check whether it applies.
- An agent can ignore the note. Whether agents now save lessons and reuse fixes
  on real tasks is what the next Terminal-Bench run will measure.
